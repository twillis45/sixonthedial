Marketing & promotion

Four phases running alongside the spine, not after it — positioning is a stage-2 input. Each phase carries an exit condition and items: the exit condition is what the phase waits on, the items are what has actually happened. A phase that has produced an asset is not a phase that has passed.

A row marked not run is never hidden by “Hide the done” and is not the same as completing it, however it is ticked — only a gate record retires an obligation. Producing the asset a test needs is not running the test, which is why phase 2 is the most-skipped phase in the doctrine. Every recorded row names the gate record it came from and its date.
